---
name: tidy-list
description: Reviews one to-do list and helps the user clear out finished or stale items.
---
Use this when the user wants to clean up or review a list.
1. Resolve the list name to its ID with the list lists tool.
2. Read the done items with the list items tool (status done), then the open items.
3. Summarise what is finished and what is still open.
4. Offer to delete finished items one at a time. Deleting cannot be undone, so name each item before you delete it.
